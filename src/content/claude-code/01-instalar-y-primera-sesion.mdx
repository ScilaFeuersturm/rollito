## Concepto

**Qué es.** Claude Code es un asistente que trabaja **dentro de tu proyecto**: lee archivos, ejecuta comandos, edita código y te pide permiso para lo que puede tener consecuencias. Se usa desde la terminal o desde la extensión de VS Code; los conceptos de este curso sirven para las dos.

**Instalación** (comandos de la documentación oficial):

- Windows, en PowerShell: `irm https://claude.ai/install.ps1 | iex`
- macOS, Linux o WSL: `curl -fsSL https://claude.ai/install.sh | bash`
- Para verificar: `claude --version`. Si dice que no encuentra `claude`, falta agregar la carpeta de instalación al PATH.

En Windows conviene tener Git for Windows instalado, así Claude Code puede usar Bash; si no, usa PowerShell.

**Primera sesión:** `cd` a la carpeta del proyecto y `claude`. La primera vez abre el navegador para iniciar sesión (si no se abre, apretá `c` para copiar el link).

## Ejemplo

Los comandos que vas a usar todos los días:

```text
claude                      abre una sesión en el proyecto actual
claude "agregá un test"     abre una sesión y arranca con ese pedido
claude -c                   continúa la última conversación de este proyecto
claude -r                   elegís una conversación anterior para retomar
claude -p "pregunta"        consulta única: responde y termina
```

Adentro de la sesión: `/help` muestra los comandos, `/exit` sale, y `?` con el campo vacío muestra los atajos de teclado.
