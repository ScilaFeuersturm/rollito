## Concepto

**Qué problema resuelve.** Sin MCP, Claude Code ve tu código y tu terminal. Con MCP puede trabajar con tus otras herramientas: leer un ticket, consultar una base de datos, mirar un diseño.

**Cómo se agregan** (sintaxis de la documentación oficial):

- Servidor remoto por HTTP: `claude mcp add --transport http <nombre> <url>`
- Servidor local por stdio: `claude mcp add <nombre> -- <comando> [args...]`. El `--` separa las opciones de Claude del comando que lanza el servidor.

**Scopes:** `local` (por defecto, solo vos en este proyecto), `project` (en `.mcp.json`, para el equipo) y `user` (vos, en todos tus proyectos).

**Administrar:** `claude mcp list`, `claude mcp get <nombre>`, `claude mcp remove <nombre>`, y `/mcp` dentro de una sesión para ver el estado e iniciar sesión con OAuth.

## Ejemplo

Ejemplos de la documentación:

```text
claude mcp add --transport http notion https://mcp.notion.com/mcp
claude mcp add --transport http compartido --scope project https://example.com/mcp
```

Después, adentro de la sesión, `/mcp` para iniciar sesión en el navegador si el servidor lo pide.
