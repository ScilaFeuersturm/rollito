## Concepto

**El objetivo.** Juntar todo el curso en un solo proyecto: que quede configurado para que trabajar con Claude Code sea rápido, predecible y seguro.

**Checklist del desafío:**

- ☐ `CLAUDE.md` corto, con comandos y reglas concretas (lección 6).
- ☐ Permisos: allow para tests y build, deny para secretos (lecciones 5 y 11).
- ☐ Una skill propia, por ejemplo `/revisar-cambios` (lección 7).
- ☐ Un hook que formatee después de editar (lección 8).
- ☐ Un subagente revisor de solo lectura (lección 10).
- ☐ Una funcionalidad hecha con modo plan, pedidos claros y tests (lecciones 2 a 4).
- ☐ Revisión con el subagente y `/diff` antes de commitear.

## Ejemplo

Así podría quedar la carpeta `.claude/` del proyecto:

```text
CLAUDE.md
.claude/
  settings.json              permisos y hooks del equipo
  settings.local.json        tus permisos personales (no se commitea)
  skills/
    revisar-cambios/
      SKILL.md
  agents/
    revisor.md
```

Cuando lo termines, mostráselo a Aramis. Este curso se revisa una vez por semana contra la documentación oficial, porque Claude Code se actualiza seguido: si algo de las lecciones no coincide con lo que ves, avisá.
