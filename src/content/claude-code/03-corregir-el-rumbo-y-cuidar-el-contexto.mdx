## Concepto

**Qué problema resuelve.** Claude Code trabaja con el **contexto** de la conversación: todo lo que se dijo, se leyó y se probó. Cuanto más limpio, mejor trabaja. Y cuando se va para otro lado, frenarlo a tiempo ahorra mucho.

**Para corregir el rumbo:**

- `Esc`: frena en el momento y conserva lo hecho.
- `Esc` `Esc` con el campo vacío, o `/rewind`: menú para volver a un punto anterior.

**Para cuidar el contexto:**

- `/clear`: conversación nueva. Usalo entre tareas sin relación.
- `/compact` con un foco: resume la conversación y libera espacio.
- `/btw pregunta`: pregunta rápida que no queda en el historial.
- `/rename nombre`: le ponés nombre a la sesión para retomarla después con `claude --resume nombre`.
- `/context`: muestra qué está ocupando el contexto.

## Ejemplo

Una sesión típica:

```text
> En @src/cuenta/servicio.ts agregá un timeout de 10 s al login
  (Claude empieza a tocar otro archivo)
[Esc]
> Solo en servicio.ts, no toques Cuenta.tsx
  (termina bien)
> /btw ¿qué código de error devuelve Firebase si no hay red?
> /clear
> Ahora otra cosa: ...
```
