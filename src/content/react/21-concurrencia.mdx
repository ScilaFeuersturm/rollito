## Concepto

**Qué problema resuelve.** Algunas actualizaciones son urgentes (el texto que escribís tiene que aparecer ya) y otras pueden esperar (filtrar 5.000 elementos). Antes de React 18, las dos competían y el campo se trababa.

- **`useTransition`**: `const [isPending, iniciarTransicion] = useTransition()`. Lo que va adentro de `iniciarTransicion` es no urgente, y `isPending` dice si está en curso.
- **`useDeferredValue`**: `const diferido = useDeferredValue(valor)`. Devuelve una versión del valor que se pone al día cuando React tiene tiempo.
