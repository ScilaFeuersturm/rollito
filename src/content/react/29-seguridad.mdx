## Concepto

**Qué problema resuelve.** El XSS (cross-site scripting) es inyectar código que se ejecuta en el navegador de otra persona: puede robar sesiones o hacer acciones en su nombre. React protege por defecto, pero tiene salidas de emergencia que hay que usar con cuidado.

1. **Texto entre llaves:** React lo escapa. Seguro.
2. **`dangerouslySetInnerHTML`:** inserta HTML crudo. Solo con HTML sanitizado.
3. **URLs que vienen de afuera:** validar el esquema (`http:`, `https:`).
