## Concepto

**Qué problema resuelve.** En lo Semi Senior viste `memo`, `useMemo` y code splitting. En el nivel Senior se espera que puedas **diagnosticar**: medir, encontrar la causa y elegir la técnica.

- **Profiler** (React DevTools): qué se dibuja, cuántas veces y cuánto tarda.
- **Virtualización:** para listas largas, se dibuja solo lo visible.
- **React Compiler:** memoriza automáticamente al compilar, si el código cumple las reglas de React.
