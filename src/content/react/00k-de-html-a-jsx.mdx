## Concepto

**Qué problema resuelve.** Ya sabés HTML. JSX es casi lo mismo, con unas pocas diferencias porque vive dentro de JavaScript.

- `class` → `className`
- `for` → `htmlFor`
- `<input>` → `<input />` (toda etiqueta se cierra)
- `style="padding: 16px"` → `style={{ padding: 16 }}`
- `onclick="..."` → `onClick={funcion}`
- valores de JavaScript entre llaves: `maxLength={60}`

Lo que aprendiste en este nivel (semántica, labels, accesibilidad, CSS) vale igual en React: **React genera ese mismo HTML**.
