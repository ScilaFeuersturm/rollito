## Concepto

**Qué problema resuelve.** React genera HTML. Si no entendés qué HTML genera ni cómo lo pinta el CSS, React se vuelve magia y los errores, misterios.

**Las tres capas de una página:**

- **HTML:** la estructura y el significado: títulos, párrafos, botones, formularios.
- **CSS:** la presentación: colores, tamaños, posiciones.
- **JavaScript:** el comportamiento: responder a un clic, pedir datos.

**La estructura mínima:** `<!DOCTYPE html>`, `<html lang="es">`, un `<head>` (codificación, viewport, título, estilos) y un `<body>` con el contenido, dentro de un `<main>`.

El navegador lee el HTML y arma el **DOM**, un árbol de objetos. CSS y JavaScript trabajan sobre ese árbol, y React también.
