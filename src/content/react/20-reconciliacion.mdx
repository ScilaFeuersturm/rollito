## Concepto

**Qué problema resuelve.** Saber cómo decide React qué conservar explica muchos bugs raros: datos que "se pasan" de un ítem a otro, un campo que pierde el foco al escribir, estado que no se resetea.

En cada dibujo, React compara el árbol nuevo con el anterior, posición por posición (la **reconciliación**):

- **Mismo tipo en la misma posición:** actualiza las props y **conserva el estado**.
- **Otro tipo:** descarta ese subárbol entero y lo vuelve a crear.
- **Otra key:** lo trata como otro componente, aunque sea del mismo tipo.
