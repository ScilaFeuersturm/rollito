## Concepto

**El enunciado:** *"Mostrá una lista desde una API REST, con loading, error con reintento y estado vacío; al tocar un ítem, andá al detalle."* Es el mismo del live coding de Android, resuelto con React y TypeScript. El código completo está en `react-samples/live-coding/` y tiene 5 tests en verde.

**Paso 1: tipos y cliente de la API.** Todo lo demás depende de esto.

> "Antes de arrancar: ¿la lista es paginada? ¿tiene que andar offline? ¿cuánto tiempo tengo? Voy de adentro hacia afuera: tipos y cliente de la API, un hook de datos, las pantallas, el routing y un test."

> "Separo el DTO, que es la forma del JSON, del modelo que usa la app, y valido lo que llega, porque TypeScript no valida en tiempo de ejecución."

> "`fetch` no rechaza ante un 404, así que reviso `ok` y clasifico la falla: sin conexión, error del cliente, del servidor o de formato."
