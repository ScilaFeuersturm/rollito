## Concepto

**Qué problema resuelve.** El HTML no es solo para que "se vea": dice **qué es** cada cosa. Eso lo usan el lector de pantalla, los buscadores y el propio navegador.

**Las etiquetas de estructura:**

- `<header>`: encabezado del sitio (logo, navegación).
- `<nav>`: navegación.
- `<main>`: el contenido principal (uno por página).
- `<section>`: una sección temática, con su título.
- `<article>`: algo independiente (una tarea, una publicación).
- `<footer>`: el pie.

**Títulos:** un `h1`, después `h2`, `h3`, sin saltear niveles.

**Controles:** `<button>` para acciones, `<a href>` para ir a otro lugar.
