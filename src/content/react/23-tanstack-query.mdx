## Concepto

**Qué problema resuelve.** Pedir datos con `useEffect` obliga a resolver a mano carga, error, reintentos, caché, pedidos duplicados y datos viejos. TanStack Query lo resuelve con dos hooks:

- **`useQuery({ queryKey, queryFn })`**: lee y cachea. Devuelve `data`, `isPending`, `isError`, `error` y `refetch`.
- **`useMutation({ mutationFn, onSuccess })`**: escribe. Al terminar, invalidás las consultas afectadas.

Todo va dentro de un `QueryClientProvider` con un `QueryClient`.
