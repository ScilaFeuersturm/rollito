## Concepto

**Qué problema resuelve.** Todo elemento es una caja. Entender cómo se mide evita los clásicos "¿por qué se me desborda?".

De adentro hacia afuera: **contenido → padding → border → margin**.

- **`box-sizing: content-box`** (por defecto): `width` = solo el contenido.
- **`box-sizing: border-box`**: `width` = contenido + padding + borde. Mucho más predecible.
