## Concepto

**Qué problema resuelve.** Un error al dibujar, sin protección, desmonta toda la app: pantalla en blanco. Un **error boundary** atrapa los errores de sus hijos y muestra un mensaje alternativo solo para esa sección.

- `static getDerivedStateFromError(error)`: guarda el error en el estado para mostrar el mensaje.
- `componentDidCatch(error, info)`: reporta el error, con `info.componentStack`.
