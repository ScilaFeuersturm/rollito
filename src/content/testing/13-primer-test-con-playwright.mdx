## Concepto

**Qué problema resuelve.** Un test E2E (de punta a punta) usa la aplicación como una persona: abre el navegador, navega, hace clic y verifica lo que ve. Playwright los escribe en TypeScript y corre en Chromium, Firefox y WebKit.

- **`playwright.config.ts`:** carpeta de tests, `baseURL`, servidor y proyectos.
- **Un test:** `test('nombre', async ({ page }) => { ... })` con acciones (`goto`, `click`, `fill`) y aserciones (`expect(...).toBeVisible()`).
- **Correrlos:** `npm run test:e2e` en Rollito (construye el sitio y después prueba).
