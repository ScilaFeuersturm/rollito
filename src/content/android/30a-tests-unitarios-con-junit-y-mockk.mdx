## Concepto

Un test unitario verifica una pieza aislada en la JVM, sin emulador. Se escribe con **JUnit** (`@Test` y aserciones) y las dependencias se reemplazan por **dobles**.

**MockK** es la librería de mocks pensada para Kotlin:

- `mockk<T>()` crea el doble.
- `every { ... } returns ...` define respuestas.
- `coEvery` y `coVerify` son las versiones para funciones `suspend`.
- `verify { ... }` comprueba que hubo una llamada.

Para corrutinas se usa `runTest`, de kotlinx-coroutines-test. Si el ViewModel usa `viewModelScope`, se reemplaza el dispatcher principal con `Dispatchers.setMain`.

## Ejemplo

Para testear el ViewModel de tareas, el repositorio es un mock que lanza `IOException` al pedirle las tareas. El test verifica que el estado termine en Error, sin red ni base de datos.
