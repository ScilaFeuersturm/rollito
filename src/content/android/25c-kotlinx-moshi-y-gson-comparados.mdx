## Concepto

**Qué problema resuelve.** Las tres librerías convierten JSON en objetos, pero se comportan distinto justo en los casos que generan bugs: campos que faltan, `null` donde no debería haber, claves nuevas del backend. Las respuestas de esta lección salen de un test que corre los mismos JSON con las tres (Kotlinx Serialization 1.13.0, Moshi 1.15.2 y Gson 2.15.0).

**Cómo funciona cada una:**

- **Gson:** reflexión en tiempo de ejecución. No conoce Kotlin: si la clase no tiene constructor sin argumentos, la crea **sin llamar al constructor**, así que ignora los valores por defecto y la nulabilidad. Está en mantenimiento.
- **Moshi:** entiende Kotlin. Funciona con reflexión (`KotlinJsonAdapterFactory`) o, mejor, con generación de código (`moshi-kotlin-codegen` + KSP).
- **Kotlinx Serialization:** un plugin del compilador genera el serializador. No usa reflexión y funciona en KMP. Es estricto por defecto.

**Qué hace cada una en cada caso** (Kotlinx · Moshi · Gson):

- Falta un campo **con** valor por defecto → usa el default · usa el default · **`null`**.
- Falta un campo **sin** valor por defecto → `MissingFieldException` · `JsonDataException` · **`null` sin avisar**.
- `null` explícito en un campo no nulable → `JsonDecodingException` (o el default, con `coerceInputValues`) · `JsonDataException` · **`null`**.
- Clave desconocida → **`JsonDecodingException`** (salvo `ignoreUnknownKeys`) · la ignora · la ignora.
- Serializar con valores por defecto → **los omite** (salvo `encodeDefaults`) · los manda · los manda.

**Cuándo elegir cuál:** Kotlinx en proyectos nuevos, sobre todo con KMP. Moshi si el equipo ya lo usa, con codegen. Gson solo en código existente, migrando de a poco.

## Ejemplo

La configuración típica de Kotlinx en un proyecto real:

```kotlin
val json = Json {
    ignoreUnknownKeys = true   // un campo nuevo del backend no rompe la app
    coerceInputValues = true   // un null o un enum desconocido usa el valor por defecto
    // encodeDefaults = true   // solo si el backend espera todos los campos al enviar
}
```

Los cinco casos verificados están en `android-samples/live-coding/app/src/test/java/com/rollito/livecoding/data/SerializacionComparadaTest.kt`.
