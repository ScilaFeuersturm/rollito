## Concepto

**Qué problema resuelve.** El ViewModel necesita decirle a la UI "navegá al detalle" o "mostrá este error una vez". Si el evento se repite, el snackbar aparece de nuevo al rotar. Si se pierde, la persona nunca se entera de que algo falló. Es la pregunta trampa clásica, porque ninguna herramienta es perfecta.

**Antes vs. ahora.** Con MVP, el Presenter llamaba a `view.showError()` y listo, salvo que la vista estuviera desconectada (entonces se perdía). Con `LiveData` apareció el famoso `SingleLiveEvent`, un parche para lo mismo. El problema siempre fue igual: un evento no es estado, pero la UI se recrea.

**Las opciones:**

- **`StateFlow`**: guarda el último valor. *A favor:* nunca se pierde. *En contra:* se repite a cada colector nuevo (rotación, volver de segundo plano).
- **`SharedFlow` sin replay**: *A favor:* no se repite y admite varios colectores. *En contra:* si nadie colecta en ese momento, el evento se descarta, aunque tenga buffer.
- **`Channel` + `receiveAsFlow()`**: *A favor:* guarda el evento hasta que alguien lo recibe y lo entrega una sola vez. *En contra:* un solo colector, y en un borde fino se puede perder; se colecta con `repeatOnLifecycle` en `Dispatchers.Main.immediate`.
- **Evento como estado** (lo que recomienda la guía de Android): el mensaje va en el `UiState` y la UI avisa cuando lo mostró. *A favor:* no se pierde ni se repite y se testea como cualquier estado. *En contra:* un poco más de código.

## Ejemplo

Simulación en Kotlin puro: el evento se emite mientras no hay pantalla (como durante una rotación) y después llegan dos pantallas, una tras otra. Predecí qué imprime antes de mirar el primer ejercicio.

Y así queda el evento como estado en un ViewModel:

```kotlin
data class PerfilUiState(val cargando: Boolean = false, val mensaje: String? = null)

class PerfilViewModel : ViewModel() {
    private val _estado = MutableStateFlow(PerfilUiState())
    val estado: StateFlow<PerfilUiState> = _estado.asStateFlow()

    fun alFallarGuardado() = _estado.update { it.copy(mensaje = "No se pudo guardar") }
    fun onMensajeMostrado() = _estado.update { it.copy(mensaje = null) }
}
```

En Compose: `LaunchedEffect(estado.mensaje)` muestra el snackbar si `mensaje` no es `null` y, al terminar, llama a `onMensajeMostrado()`.
