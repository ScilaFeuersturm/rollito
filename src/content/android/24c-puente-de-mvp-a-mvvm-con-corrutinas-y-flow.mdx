## Concepto

**Qué problema resuelve.** En MVP había tres peleas constantes: el Presenter se perdía al rotar, la referencia a la vista causaba fugas y las tareas en segundo plano había que cortarlas a mano en `onDestroy`. MVVM con `ViewModel`, corrutinas y `StateFlow` resuelve las tres con piezas que ya conocen el ciclo de vida.

**Antes vs. ahora.**

- `presenter.attach(view)` / `detach()` → la vista observa `estado`. El ViewModel no la conoce.
- `view.showLoading()`, `view.showError()` → un solo `UiState` sellado con todos los casos.
- `AsyncTask` + cancelar en `onDestroy` → `viewModelScope.launch`, que se cancela solo en `onCleared`.
- Presenter recreado (o retenido con trucos) al rotar → `ViewModel` retenido por el `ViewModelStore`.

El ViewModel **expone estado** y **recibe eventos**. La vista no recibe órdenes como `showLoading()`: dibuja lo que dice el estado. Por eso el estado se modela como un tipo sellado, y la pantalla nunca puede estar cargando y con error a la vez.

## Ejemplo

```kotlin
sealed interface TareasUiState {
    data object Cargando : TareasUiState
    data class Contenido(val tareas: List<Tarea>) : TareasUiState
    data class Error(val mensaje: String) : TareasUiState
}

class TareasViewModel(private val repo: TareasRepository) : ViewModel() {
    private val _estado = MutableStateFlow<TareasUiState>(TareasUiState.Cargando)
    val estado: StateFlow<TareasUiState> = _estado.asStateFlow()

    init { cargar() }

    fun cargar() {
        viewModelScope.launch {
            _estado.value = TareasUiState.Cargando
            _estado.value = try {
                TareasUiState.Contenido(repo.obtenerTareas())
            } catch (e: IOException) {
                TareasUiState.Error("No hay conexión")
            }
        }
    }
}
```

En la pantalla se colecta con `val estado by viewModel.estado.collectAsStateWithLifecycle()` y un `when (estado)` dibuja cada caso. `obtenerTareas()` es `suspend`, y el repositorio usa `withContext(Dispatchers.IO)` cuando hace falta: el ViewModel no sabe de hilos.
