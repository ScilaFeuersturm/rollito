## Concepto

Una `data class` sirve para representar datos como el identificador, el título y el estado de una tarea. Kotlin genera operaciones como igualdad y copia a partir de las propiedades del constructor principal. [Data classes en Kotlin](https://kotlinlang.org/docs/data-classes.html)

## Ejemplo

`copy` crea otra tarea con el estado actualizado y conserva el identificador. Los dos últimos resultados comprueban la igualdad de valores con otra tarea completada y que el identificador se mantiene.
