## Concepto

Una capa de red transforma llamadas HTTP en resultados para la app. Separá problemas de transporte, autenticación, respuestas fallidas y errores de datos.

## Ejemplo

La lista devuelve 500 y se puede reintentar. Una respuesta 401 puede requerir renovar la sesión.
