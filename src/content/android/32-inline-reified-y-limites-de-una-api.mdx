## Concepto

Inline puede insertar el cuerpo de la función y habilitar un parámetro reified. Esto permite comprobar ese tipo, con límites derivados del borrado de tipos.

## Ejemplo

Un filtro puede recuperar los elementos String de una colección mixta. La JVM no verifica todos los argumentos de un tipo genérico anidado en esa operación.
