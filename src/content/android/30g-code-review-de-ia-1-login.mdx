## Concepto

Le pediste a la IA: *"Hacé el ViewModel del login y guardá el token cuando sale bien"*. Te devolvió el código de abajo. Compila y, con usuario y clave correctos, funciona.

Hacé el review como si fuera el PR de alguien del equipo. Hay **seis problemas**: de ciclo de vida, de seguridad, de diseño del estado y de manejo de errores. Buscalos antes de abrir las respuestas.

## Ejemplo

```kotlin
object SesionManager {
    lateinit var context: Context

    fun guardarToken(token: String) {
        Log.d("Sesion", "Token guardado: $token")
        context.getSharedPreferences("sesion", Context.MODE_PRIVATE)
            .edit().putString("token", token).apply()
    }
}

class LoginViewModel(private val api: AuthApi) : ViewModel() {
    val estado = MutableStateFlow<LoginState>(LoginState.Inicial)

    fun login(usuario: String, clave: String) {
        GlobalScope.launch {
            val respuesta = api.login(usuario, clave)
            SesionManager.guardarToken(respuesta.body()!!.token)
            estado.value = LoginState.Exito
        }
    }
}
```
