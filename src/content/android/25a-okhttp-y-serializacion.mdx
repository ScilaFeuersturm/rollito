## Concepto

Retrofit define la API como una interfaz, pero por debajo las llamadas las hace **OkHttp**. En OkHttp se configuran:

- Los **timeouts**: conexión, lectura y escritura.
- Los **interceptores**, que ven pasar cada pedido y respuesta. Sirven para agregar el header de autorización, loguear o medir.

El JSON se convierte a objetos con una librería de **serialización**. Las dos más usadas en Kotlin son **Kotlinx Serialization** (plugin del compilador, sin reflexión, multiplataforma) y **Moshi** (con generación de código por KSP o con reflexión).

## Ejemplo

Un interceptor agrega `Authorization: Bearer <token>` a todos los pedidos. Si la API responde 401, un `Authenticator` de OkHttp renueva el token y reintenta una vez.

El `TareaDto` está marcado como `@Serializable`. Si la API agrega un campo nuevo, la configuración `ignoreUnknownKeys = true` evita que la app se rompa.
