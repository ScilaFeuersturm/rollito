## Concepto

**Qué problema resuelve.** Las funciones agrupan lógica reutilizable. Kotlin suma dos cosas que en Java no había y que en Swift sí: valores por defecto y argumentos con nombre.

- **Declaración:** `fun sumar(a: Int, b: Int): Int { return a + b }`.
- **Una sola expresión:** `fun duplicar(n: Int) = n * 2`.
- **Valores por defecto:** `saludo: String = "Hola"`.
- **Argumentos con nombre:** `saludar(saludo = "Buen día", nombre = "Beto")`, en cualquier orden.
- **Sin retorno:** devuelven `Unit` (el `Void` de Swift).

**Desde Swift:** no hay labels externos (`func saludar(a nombre: String)`). Y la palabra es `fun`, no `func`.
