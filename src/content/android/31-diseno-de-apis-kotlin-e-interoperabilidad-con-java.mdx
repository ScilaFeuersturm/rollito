## Concepto

Una API pública debe declarar contratos claros de nullability, errores y compatibilidad. Los tipos de plataforma de Java pueden dejar incertidumbre sobre si un valor es nulo.

## Ejemplo

Un proveedor Java puede devolver null y Kotlin puede permitir usar el resultado con supuestos distintos. Validá en el límite y exponé un tipo claro al resto de la app.
