## Concepto

**Para qué sirve.** Una referencia rápida para quien viene de Swift (o vuelve a Kotlin después de un tiempo). Cada fila tiene su lección en este nivel.

- `let` / `var` → `val` / `var`
- `"\(nombre)"` → `"$nombre"` o `"${expresion}"`
- `func` → `fun`, sin labels externos
- `Void` → `Unit`
- `switch` / `case` → `when`
- `1...3` / `0..<3` → `1..3` / `0 until 3`
- `String?` → `String?` (igual)
- `??` → `?:` (Elvis)
- `if let x = y` → `y?.let { }` o `if (y != null)` con smart cast
- `guard let x = y else { return }` → `val x = y ?: return`
- `!` (force unwrap) → `!!`
- `struct` → `data class` (ojo: es una clase, con `val` y `copy`)
- `enum` simple → `enum class`
- `enum` con valores asociados → `sealed interface`
- `static let` / `static func` → dentro de `companion object`
- `static let shared = X()` → `object X`
- `protocol` → `interface`
- `extension Tipo { func f() }` → `fun Tipo.f()`
- clases abiertas por defecto → **cerradas** por defecto (`open` para heredar)
- `$0` → `it`
- `[String]` / `[String: Int]` → `List<String>` / `Map<String, Int>`

## Ejemplo

Lo mismo, en los dos lenguajes:

```swift
// Swift
struct Tarea { let titulo: String; var hecha = false }
let pendientes = tareas.filter { !$0.hecha }.map { $0.titulo }
guard let primera = pendientes.first else { return }
print("Primera: \(primera)")
```

```kotlin
// Kotlin
data class Tarea(val titulo: String, val hecha: Boolean = false)
val pendientes = tareas.filter { !it.hecha }.map { it.titulo }
val primera = pendientes.firstOrNull() ?: return
println("Primera: $primera")
```

Una diferencia sutil: en Swift, `first` ya devuelve un Optional; en Kotlin, `first()` lanza una excepción si la lista está vacía, y `firstOrNull()` devuelve nulable.
