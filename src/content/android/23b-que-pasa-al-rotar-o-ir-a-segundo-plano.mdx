## Concepto

**Qué problema resuelve.** Una rotación destruye y recrea la Activity; ir a segundo plano la detiene. Según el scope donde corre una corrutina y cómo se colecta un flow, el trabajo sigue, se cancela, se repite o desperdicia batería. En entrevista te lo preguntan como "¿qué pasa si…?".

**Antes vs. ahora.** En la época de MVP manejabas esto a mano: cancelabas en `onDestroy`, te desuscribías en `onStop` y retenías el Presenter con trucos. Hoy cada pieza tiene un ciclo de vida definido:

- `viewModelScope`: vive lo que el ViewModel. Sobrevive a la rotación y se cancela cuando la pantalla se va de verdad.
- `lifecycleScope`: vive lo que la Activity (o el Fragment). Se cancela en `onDestroy`, incluida la rotación.
- `repeatOnLifecycle(STARTED)`: ejecuta el bloque mientras la pantalla está visible; lo cancela en `onStop` y lo reinicia en `onStart`.
- `collectAsStateWithLifecycle()`: lo mismo, para Compose.

## Ejemplo

Cinco escenarios. Para cada uno, pensá qué pasa al rotar y al ir a segundo plano antes de responder.

**Escenario 1:** carga en el ViewModel.

```kotlin
class PerfilViewModel(private val repo: PerfilRepository) : ViewModel() {
    private val _estado = MutableStateFlow<PerfilUiState>(PerfilUiState.Cargando)
    val estado = _estado.asStateFlow()

    init {
        viewModelScope.launch { _estado.value = PerfilUiState.Listo(repo.cargar()) } // tarda 3 s
    }
}
```

**Escenario 2:** la misma carga, en la Activity.

```kotlin
override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    lifecycleScope.launch { mostrar(repo.cargar()) } // tarda 3 s
}
```

**Escenario 3:** colectar sin ciclo de vida.

```kotlin
lifecycleScope.launch {
    viewModel.ubicacion.collect { mostrar(it) }
}
```

**Escenario 4:** colectar con `repeatOnLifecycle`.

```kotlin
lifecycleScope.launch {
    repeatOnLifecycle(Lifecycle.State.STARTED) {
        viewModel.ubicacion.collect { mostrar(it) }
    }
}
```

**Escenario 5:** Compose + `stateIn`.

```kotlin
// ViewModel
val estado = repo.tareas()
    .map { TareasUiState.Contenido(it) }
    .stateIn(viewModelScope, SharingStarted.WhileSubscribed(5000), TareasUiState.Cargando)

// Pantalla
val estado by viewModel.estado.collectAsStateWithLifecycle()
```
