## Concepto

**Lo nuevo:** varios pines a la vez y funciones propias para no repetir código.

- Cada LED en su pin, cada uno con su resistencia.
- Constantes con nombre (`const int rojo = 12;`): el código se lee solo.
- Una función propia con parámetros: `void encender(int pin, int ms) { … }`.
