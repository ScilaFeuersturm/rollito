## Concepto

**Lo nuevo:** sensores que son resistencias variables.

Una **fotorresistencia (LDR)** cambia su resistencia con la luz: mucha luz, poca resistencia. El Arduino no mide resistencia, mide voltaje. Por eso se arma un **divisor de tensión**:

- LDR entre **5V** y **A0**.
- Resistencia de **10 kΩ** entre **A0** y **GND**.

El voltaje en A0 cambia con la luz y se lee con `analogRead`.

## Ejemplo

**Luz nocturna (código para la placa; se puede probar en el simulador con el potenciómetro como si fuera la luz):**

```cpp
const int led = 13;
const int umbral = 300;   // calibralo con el monitor serie

void setup() {
  pinMode(led, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int luz = analogRead(A0);
  Serial.println(luz);
  if (luz < umbral) {
    digitalWrite(led, HIGH);   // está oscuro
  } else {
    digitalWrite(led, LOW);
  }
  delay(200);
}
```

Para probar el circuito completo con cables y componentes, abrí un proyecto nuevo de **Arduino Uno** en [wokwi.com](https://wokwi.com), un simulador gratuito que funciona en el navegador.
