## Concepto

**La estructura de todo programa (sketch) de Arduino:**

```cpp
void setup() {
  // corre una vez: configurar
}

void loop() {
  // se repite para siempre
}
```

**Las tres funciones del primer programa:**

- `pinMode(pin, OUTPUT)`: el pin va a dar voltaje.
- `digitalWrite(pin, HIGH)` / `LOW`: 5 V o 0 V.
- `delay(ms)`: espera, en milisegundos.

**Desde Kotlin o Swift:** es C++, pero lo que usás acá se parece mucho: `int` para enteros, `;` al final de cada línea y llaves para los bloques. `const int led = 13;` es como un `val`.
