## Concepto

**El módulo estrella del kit**, y el que más fácil se quema.

**Alimentación: 3,3 V.** El VCC del RC522 va al pin **3.3V** del Arduino, **nunca a 5V**.

**Conexión (SPI) con el Uno:**

- **SDA (SS)** → pin 10
- **SCK** → pin 13
- **MOSI** → pin 11
- **MISO** → pin 12
- **RST** → pin 9
- **GND** → GND
- **3.3V** → 3.3V
- IRQ: no se conecta.

**Librería:** **MFRC522**, desde el Gestor de librerías del IDE.

## Ejemplo

**Leer el UID de una tarjeta (basado en el ejemplo de la librería MFRC522):**

```cpp
#include <SPI.h>
#include <MFRC522.h>

MFRC522 lector(10, 9);   // SS en el pin 10, RST en el pin 9

void setup() {
  Serial.begin(9600);
  SPI.begin();
  lector.PCD_Init();
  Serial.println("Acercá una tarjeta");
}

void loop() {
  if (!lector.PICC_IsNewCardPresent() || !lector.PICC_ReadCardSerial()) return;

  Serial.print("UID:");
  for (byte i = 0; i < lector.uid.size; i++) {
    Serial.print(" ");
    Serial.print(lector.uid.uidByte[i], HEX);
  }
  Serial.println();
  lector.PICC_HaltA();
}
```
