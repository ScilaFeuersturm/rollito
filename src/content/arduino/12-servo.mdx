## Concepto

**Lo nuevo:** mover algo a una posición exacta.

Un **servo** gira a un ángulo que le indicás (0 a 180 grados en el SG90). Se controla con la librería **Servo**, que viene con el IDE:

- `#include <Servo.h>` y `Servo miServo;`
- En `setup()`: `miServo.attach(9);`
- Para moverlo: `miServo.write(angulo);`

**Alimentación:** un SG90 solo, al 5V de la placa; varios, fuente aparte con GND común.

## Ejemplo

**Barrido del servo (código para la placa):**

```cpp
#include <Servo.h>

Servo miServo;

void setup() {
  miServo.attach(9);
}

void loop() {
  for (int angulo = 0; angulo <= 180; angulo += 10) {
    miServo.write(angulo);
    delay(100);
  }
  for (int angulo = 180; angulo >= 0; angulo -= 10) {
    miServo.write(angulo);
    delay(100);
  }
}
```
