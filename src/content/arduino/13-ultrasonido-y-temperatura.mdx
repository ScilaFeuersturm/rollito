## Concepto

**Dos sensores muy comunes en los kits** (si el tuyo los trae):

**HC-SR04 (distancia):** 4 pines: VCC (5V), Trig, Echo y GND. Se manda un pulso por Trig y se mide la duración del eco en Echo con `pulseIn`.

**DHT11 (temperatura y humedad):** 3 pines (o 4): VCC (5V), datos y GND. Necesita la librería **"DHT sensor library"** (de Adafruit), que se instala desde el Gestor de librerías del IDE.

## Ejemplo

**Distancia con el HC-SR04 (Trig al pin 9, Echo al pin 10):**

```cpp
const int trig = 9;
const int echo = 10;

void setup() {
  pinMode(trig, OUTPUT);
  pinMode(echo, INPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(trig, LOW);
  delayMicroseconds(2);
  digitalWrite(trig, HIGH);
  delayMicroseconds(10);       // pulso de 10 µs
  digitalWrite(trig, LOW);
  long duracion = pulseIn(echo, HIGH);
  float distancia = duracion * 0.034 / 2;
  Serial.println(distancia);
  delay(200);
}
```

**Temperatura con el DHT11 (datos al pin 2, librería de Adafruit):**

```cpp
#include <DHT.h>

DHT dht(2, DHT11);

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  delay(2000);                       // el DHT11 es lento
  float temperatura = dht.readTemperature();
  if (isnan(temperatura)) {
    Serial.println("No se pudo leer el sensor");
    return;
  }
  Serial.println(temperatura);
}
```

Para probar el circuito completo con cables y componentes, abrí un proyecto nuevo de **Arduino Uno** en [wokwi.com](https://wokwi.com), un simulador gratuito que funciona en el navegador. Verificá en el Gestor de librerías el nombre exacto de la librería DHT antes de instalarla.
