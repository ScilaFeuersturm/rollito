## Concepto

Cuando tocás **Agregar**, primero se verifica si la tarea se puede guardar. Si se guardó, la app abre su detalle. VIPER, descrita originalmente para iOS, separa cinco responsabilidades. [Architecting iOS Apps with VIPER](https://www.objc.io/issues/13-architecture/viper/)

- **View** muestra el resultado y comunica las acciones.
- **Interactor** ejecuta el caso de uso, valida el título y guarda la tarea.
- **Presenter** interpreta el resultado y coordina qué mostrar y cuándo navegar.
- **Entity** representa la tarea con su identificador y título.
- **Routing** implementa cómo se abre el detalle.

## Ejemplo

El router de consola imprime el destino que se abriría en una app. El interactor devuelve el identificador y el título en un resultado y conserva la entidad dentro del caso de uso.

```text
Vista → Presentador → Interactor → Entidad
Vista ← Presentador ← resultado del caso de uso
          Presentador → Router → Detalle (si se guardó)
```
